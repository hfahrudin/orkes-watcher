# Security Policy

## Supported Versions

Orkes Watcher has not made a versioned release yet — the project is in the design/
pre-implementation stage. Once releases begin, supported versions will be listed here.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for a security vulnerability.

Instead, report it privately by emailing **fahrudinhasby12@gmail.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept if you have one
- Any suggested mitigation, if known

You should expect an acknowledgment within a few days. Once the issue is confirmed, we'll
work on a fix and coordinate disclosure timing with you before making it public.

## Scope

Given the project's current stage, this applies to anything published under this
organization/repo — including the design docs and mockups — but will primarily matter once
the SDK, backend, and dashboard have real deployments handling customer data (API keys,
traced agent state).
