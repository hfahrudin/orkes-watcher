# Watcher 0.1.0

First release. Accepts orkes trace contract [1.0](../contracts/contract-1.0.md).

## Added

- **Trace ingest** for orkes contract 1.0: `POST /ingest/events` with project ingest keys, and
  `GET /version` so a sender can check compatibility before sending.
- **Live trace inspector**: a graph of each run that updates while it runs, with pan and zoom,
  a timeline view, and the raw events. Selecting a node or edge shows its state snapshot,
  function calls and LLM calls.
- **Run output**: the run page shows the graph's final state, as "Output" for finished runs and
  "State at failure" for failed ones (contract 1.0 `final_state`).
- **Failure details**: the error, a collapsible traceback, and the node the run failed in.
- **Abandoned runs**: a run that stops sending is marked failed after a per-project timeout.
- **Dashboard**: runs by outcome over time, p50/p95 run time, slowest nodes, top errors and
  failures by node, filtered by time range and graph.
- **Exports**: runs list as CSV or JSON, the dashboard summary, and a single run as JSON.
- **Projects, API keys and access**: ingest and read-only keys, Admin / Developer / Viewer
  roles with per-project grants, and an invite-and-activate flow for new accounts.
- **Retention and sampling** per project, including keeping traces forever.
- **Self-hosting** with one `docker compose up`.
- **Docs in the app**: the version in the sidebar links to this changelog and to the contract.

## Fixed

- Ingest rejects bodies with `NaN` / `Infinity`, over-deep nesting or out-of-range times with a
  clear `422` instead of failing later.
- The last admin can't be removed or demoted, and changing a password signs out other sessions.
- Live runs show correct counts and a stable graph layout while they stream.
